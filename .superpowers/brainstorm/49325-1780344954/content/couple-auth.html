Hur loggar brudparet in?

De behöver skapa eventet, välja stil — och komma tillbaka nästa dag för att se albumet.

A

Magic link via e-post

Anger sin e-post → får en länk → klickar → inloggad. Inga lösenord. Enklast att bygga för MVP. Fungerar bra när de ska komma tillbaka nästa dag.

B

E-post + lösenord

Klassisk registrering. Mer friktion vid signup men lättare att logga in igen. Supabase Auth hanterar det enkelt.

C

Google / Apple Sign-in

En klick, inget lösenord att komma ihåg. Mest friktionsfritt men kräver OAuth-setup. Bra om målgruppen är tech-bekväm.
