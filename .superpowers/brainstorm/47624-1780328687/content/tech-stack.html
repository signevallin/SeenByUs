Tech stack

Vad vill du bygga på? Välj det som passar bäst för dig.

A

Next.js + Supabase

Full-stack React-framework med inbyggd routing, server actions och API-routes. Supabase för databas, auth och storage. Enkelt att deploya på Vercel. Bra för PWA.

B

React (Vite) + Firebase

Snabb frontend-setup. Firebase för realtime-databas, auth och storage. Mer "frontend-first", Firebase sköter backenden. Sämre för komplexa API-operationer.

C

Next.js + Cloudinary + Prisma/Postgres

Next.js för allt. Cloudinary för bildlagring och AI-transformationer (har inbyggda filter). Postgres för data. Mer kontroll, något mer komplex setup.
